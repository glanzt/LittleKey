# PRD — ציידת האותיות (Letter Hunter)

## 1. סקירה כללית

**ציידת האותיות** היא אפליקציית ווב חינוכית ללימוד הקלדה בעברית לילדים. הילד שומע אות, מזהה אותה על המקלדת ולוחץ — ובכך רוכש מיומנות הקלדה דרך משחק קולי אינטראקטיבי.

| שדה | ערך |
|---|---|
| **שם המוצר** | ציידת האותיות (Letter Hunter) |
| **קהל יעד** | ילדים בגילאי 5–10 + הורים |
| **פלטפורמה** | Web (Desktop — דורש מקלדת פיזית) |
| **סטאטוס** | MVP פעיל |

---

## 2. בעיה

ילדים בישראל נחשפים למקלדת בגיל צעיר אך אין כלי ייעודי, מהנה ומבוסס-משחק שמלמד אותם את מיקום האותיות העבריות על המקלדת. לימוד הקלדה קיים בעיקר באנגלית, ואין פתרון מקביל טוב בעברית.

---

## 3. פתרון

משחק קולי שבו:
1. המערכת משמיעה את שם האות בעברית (הקלטה אנושית).
2. הילד צריך למצוא את האות על המקלדת וללחוץ עליה.
3. המערכת נותנת פידבק מיידי — קולי וחזותי.
4. ההורה יכול לעקוב אחרי ההתקדמות דרך דשבורד.

---

## 4. קהל יעד ופרסונות

### 4.1 הילד (משתמש ראשי)
- גיל: 5–10
- מטרה: ללמוד היכן כל אות עברית נמצאת על המקלדת
- צורך: חוויה מהנה, פשוטה, עם חיזוקים חיוביים

### 4.2 ההורה (משתמש משני)
- מטרה: לעקוב אחרי התקדמות הילד/ים
- צורך: לראות סטטיסטיקות, לנהל פרופילים, להתאים הגדרות

## 6. ארכיטקטורה טכנית

### 6.1 Tech Stack

| שכבה | טכנולוגיה |
|---|---|
| **Frontend** | Next.js 14 (App Router), React 18, JSX |
| **Backend** | Next.js API Routes |
| **Database** | PostgreSQL + Prisma ORM |
| **Auth** | NextAuth.js v5 (Google + Credentials) |
| **Styling** | Inline styles (JS objects) |
| **Audio** | Web Audio API + הקלטות .m4a |

### 6.2 מודלים (Database Schema)

```
User
├── Account (OAuth)
├── Session (NextAuth)
└── ChildProfile (1:N)
    ├── UserSettings (1:1, JSON)
    ├── UserLevelProgress (1:N, per level)
    ├── UserLetterStats (1:N, per letter)
    └── UserGameSession (1:N, session history)
```

### 6.3 API Routes

| Method | Route | תיאור |
|---|---|---|
| `POST` | `/api/auth/register` | הרשמה עם אימייל/סיסמה |
| `GET/POST` | `/api/auth/[...nextauth]` | NextAuth handlers |
| `GET` | `/api/profiles` | רשימת פרופילי ילדים |
| `POST` | `/api/profiles` | יצירת פרופיל |
| `DELETE` | `/api/profiles/[id]` | מחיקת פרופיל |
| `GET` | `/api/progress?profileId=` | שליפת התקדמות |
| `POST` | `/api/progress` | עדכון התקדמות |
| `POST` | `/api/progress/session` | שמירת סשן משחק |

## 7. תזרים משתמש (User Flows)

### 7.1 Flow ראשוני
```
Landing Page → הרשמה/כניסה (או מצב אורח)
  → בחירת/יצירת פרופיל ילד
    → מסך רמות → בחירת רמה → משחק
      → סיכום סשן → חזרה לרמות
```

### 7.2 Flow משחק (Game Loop)
```
1. המערכת בוחרת אות
2. השמעת שם האות
3. הילד לוחץ מקש
4. אם נכון → פידבק חיובי → אות הבאה
5. אם שגוי → פידבק שלילי → ניסיון נוסף
6. אחרי X אותיות → מסך סיכום
```

### 7.3 Flow הורה
```
דשבורד → בחירת לשונית:
  - Overview: סטטיסטיקות כלליות
  - Letters: פירוט לכל אות
  - Sessions: היסטוריית סשנים
```

## 11. סיכום

ציידת האותיות היא MVP פעיל עם ליבת משחק מלאה, מערכת רמות, ניהול פרופילים, דשבורד הורים וסנכרון ענן. המוצר פותר בעיה אמיתית — אין כלי עברי מקביל ללימוד מיקום אותיות על המקלדת — ומספק חוויית למידה אינטראקטיבית דרך אודיו ומשחק.
